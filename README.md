# 🎵 MixMusic iOS

Klien musik native iOS modern berbasis SwiftUI untuk memutar lagu dari YouTube Music & Spotify tanpa iklan, lengkap dengan lirik tersinkron (*synced lyrics*) via LRCLIB, serta background playback & lock screen integration.

---

## ✨ Fitur Utama
- **Background Audio Playback:** Musik tetap berputar saat iPhone dikunci atau saat membuka aplikasi lain.
- **Lock Screen & Control Center Player:** Menampilkan judul lagu, nama artis, artwork album, dan kontrol Play/Pause/Seek langsung di layar kunci.
- **Pencarian Terpadu:** Cari jutaan lagu, artis, dan album dari YouTube Music & Spotify secara instan.
- **Lirik Real-time Tersinkron (LRC):** Lirik bergerak kata demi kata layaknya Apple Music.
- **Tanpa Perlu Akun Berbayar:** Siap pakai tanpa langganan YouTube Premium ataupun Spotify Premium.

---

## 📲 Cara Install ke iPhone via Sideloadly (Gratis)

1. Buka tab **Actions** di repositori GitHub ini.
2. Klik workflow run terbaru, lalu download file **`MixMusic-iOS.zip`** (di dalamnya ada file **`MixMusic-iOS.ipa`**).
3. Buka aplikasi **Sideloadly** di laptop Windows atau Mac:
   - Hubungkan iPhone kamu ke laptop menggunakan kabel data.
   - Seret file `MixMusic-iOS.ipa` ke dalam jendela Sideloadly.
   - Masukkan Apple ID gratis milikmu di kolom *Apple ID*.
   - Klik tombol **Start**.
4. Di iPhone kamu:
   - Buka **Settings (Pengaturan)** ➔ **General (Umum)** ➔ **VPN & Device Management**.
   - Pilih akun Apple ID kamu, lalu klik **Trust (Percayai)**.
5. Selesai! Buka aplikasi **MixMusic** di iPhone dan nikmati musik favoritmu tanpa jeda iklan! 🎧
