# 🎵 EmsaMusic iOS

Aplikasi pemutar musik native iOS modern berbasis SwiftUI untuk memutar lagu dari YouTube Music & Spotify tanpa iklan, lengkap dengan lirik tersinkron (*synced lyrics*) via LRCLIB, background playback, antrean lagu, daftar putar kustom, serta lock screen integration.

---

## ✨ Fitur Lengkap EmsaMusic
- **🏠 Beranda & Tangga Lagu Tren:** Menampilkan rekomendasi lagu terpopuler, pilihan cepat (Quick Picks), dan suasana hati/genre (Chill, Fokus Kerja, Olahraga, Akustik, dll).
- **🔍 Pencarian Cepat & Filter:** Cari jutaan lagu, artis, dan album dari YouTube Music secara instan tanpa perlu login akun.
- **🎧 Pemutar Mini & Layar Penuh:** Dilengkapi waveform scrubber, pengatur kecepatan putar (0.75x s.d 2.0x), acak (*shuffle*), dan putar ulang (*repeat*).
- **🌙 Sleep Timer Terintegrasi:** Musik otomatis mati sesuai timer (15, 30, 45, 60 menit atau di akhir lagu yang sedang diputar).
- **🎤 Lirik Karaoke Real-time:** Menampilkan lirik lagu tersinkron kata per kata (*synced LRC lyrics*) dengan auto-scroll lembut.
- **📚 Pustaka Pribadi (Library & Mixes):** Simpan lagu favorit ke *Lagu yang Disukai*, buat *Daftar Putar Kustom (Mixes)*, dan catat riwayat lagu yang baru saja diputar.
- **📱 Background Audio & Lock Screen:** Lagu tetap berputar saat layar iPhone terkunci atau membuka aplikasi lain, lengkap dengan artwork dan kontrol di Control Center & Dynamic Island.

## 📲 Cara Install ke iPhone via Sideloadly (Gratis)

1. Buka tab **Releases** atau **Actions** di repositori GitHub ini.
2. Download file **`EmsaMusic-iOS.ipa`**.
3. Buka aplikasi **Sideloadly** di laptop Lenovo milikmu:
   - Hubungkan iPhone kamu ke laptop menggunakan kabel data USB.
   - Seret (*drag & drop*) file `EmsaMusic-iOS.ipa` ke dalam jendela Sideloadly.
   - Masukkan Apple ID gratis milikmu di kolom *Apple ID*.
   - Klik tombol **Start**.
4. Di iPhone kamu:
   - Buka **Settings (Pengaturan)** ➔ **General (Umum)** ➔ **VPN & Device Management**.
   - Pilih akun Apple ID kamu, lalu klik **Trust (Percayai)**.
5. Selesai! Buka aplikasi **EmsaMusic** di iPhone dan nikmati musik favoritmu tanpa jeda iklan! 🎧
